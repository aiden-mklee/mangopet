## 스토어 등록정보
- 간단한 설명(80자):
```
한 번에 10초씩 돌보면 며칠 뒤 다 자라는 도트 펫 키우기. 24종 도감을 채워요!
```
- 자세한 설명(4000자, 앱스토어와 같은 글):
```
한 번에 10초씩 돌보면 며칠 뒤 다 자라 도감에 남는 도트 펫 키우기예요.
오래 붙잡고 있을 시간이 없는 날에도, 하루 몇 번 잠깐씩 들르면 돼요.
한 마리는 3~7일이면 다 자라요. 도감은 모두 24종이에요.

돌보는 대로 모습이 달라져요. 아침에 자주 오면 해, 밤에 자주 오면 달, 간식을 좋아하면 통통, 오래 비우면 야생 모습으로 자라요. 다 자란 펫은 도감에 들어가고, 다음 펫을 키우면 도감이 한 칸 더 채워져요.

- 도감 채우기 — 곰·고양이·토끼·개구리·펭귄·병아리, 동물마다 4가지 모습. 반짝이 펫도 있어요.
- 오늘의 깜짝 시간 — 하루 한 번, 언제일지 모르는 30분에 유성우·무지개 같은 일이 생기고 특별한 걸 받아요.
- 펫마다 버릇 — 고양이는 꼬리를 살랑, 개구리는 파리를 쏙. 가만히 보고 있어도 귀여워요.
- 바쁜 날도 괜찮게 — 오래 못 돌보면 잠깐 가출했다가 몇 시간 뒤 돌아와요. 밤 근무 리듬도 고를 수 있어요.
- 더 즐길 거리 — 키링 30종과 꾸미기, 잠깐 더 놀고 싶을 땐 미니게임 5종.
- 자랑하기 — 다 키운 펫은 카드로 남아요. 사진으로 저장하거나 친구에게 보낼 수 있어요.
- 돌볼 때 알림 — 알림을 켜 두면 돌볼 때를 알려 줘요.
- 기록 옮기기 — 폰을 바꿔도 설정에서 키우던 기록을 옮길 수 있어요.
```

## 앱 콘텐츠 (정책 질문)
- 개인정보처리방침: `https://aiden-mklee.github.io/mangopet/privacy.html`
- 앱 액세스 권한: 모든 기능을 제한 없이 이용 가능(로그인 없음)
- 광고: 광고 없음
- 콘텐츠 등급(IARC 설문): 카테고리 '게임'. 폭력·공포·성적 내용·욕설·약물·도박·사용자 간 소통·위치 공유·디지털 상품 구매 모두 '아니요' → 전체이용가가 나와요
- 타겟층: **13~15세, 16~17세, 18세 이상**만 고르기. 13세 미만을 고르면 가족 정책 심사가 붙고, 나중에 넣을 보상형 광고도 아동용 광고 네트워크로 제한돼요. "어린이의 관심을 끌 수 있나요?"에는 사실대로 답하기
- 데이터 보안: "필요한 사용자 데이터를 수집하거나 공유하나요?" → **아니요**(기록은 폰 안에만, 서버 없음)
- 뉴스 앱·정부 앱·금융·건강·코로나 앱: 모두 아니요
- 광고 ID: 쓰지 않음
