알림이 안 와요

휴대폰 설정에서 망고펫의 알림을 켜 주세요. 아이폰은 설정 → 망고펫 → 알림, 안드로이드는 설정 → 애플리케이션 → 망고펫 → 알림입니다. 알림은 하루 몇 번만, 필요한 것을 묶어서 보내요. 밤 10시부터 아침 8시까지는 보내지 않아요.

다른 폰으로 옮기고 싶어요

설정 → 기록 → 내보내기로 나온 코드를 새 폰의 설정 → 기록 → 가져오기에 붙여 넣으면 됩니다. 기록은 기기에만 저장되기 때문에, 앱을 지우기 전에 꼭 내보내 두세요.

아이가 집을 나갔어요

느긋 모드에서 오래 돌보지 않으면 편지를 남기고 잠깐 집을 나가요. 3시간쯤 지나면 돌아와요.

기록을 지우고 싶어요

설정 → 기록 → 모든 기록 지우기를 누르면 이 기기의 기록과 예약된 알림이 모두 지워집니다. 서버에 저장되는 정보는 없습니다.
